- 来源：真机录屏 `20260814_002537.mp4` 第 323 帧，桌面 1920×1080，按 capture 报的
  客户端矩形 `(203,84) 1600×900` 裁出。**不是合成帧。**
- 现场：`trace_lab_20260814_002541.jsonl` tick 4 点了 `stage_target_1-8 @ (1280,606)`
  （对应客户端 `(1077,522)`，坐标本身没错），但两秒后高亮仍在 **1-1**——首次点击被
  窗口激活吃掉了。脚本随后按「同名目标 + 相邻关卡 + 有开始按钮」的间接证据放行，
  于是开了 1-1。
- 用途：钉住 `selected_stage_row()` 必须读出高亮行 = `1-1`，以及目标为 `1-8` 时
  L0 必须重点目标行而不是点开始游戏。
- 注意：这是 mp4 抽帧，有压缩噪声。整圈亮边（几千像素）判得稳，但 0.85 阈值的
  小模板匹配（如 `roomStart`）在这张图上会掉下来——实机 PrintWindow 帧是 0.994。
  需要「开始游戏」按钮的用例请自行注入命中，不要靠这张图做模板断言。
