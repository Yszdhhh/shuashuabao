## P0（已修）：第二局传家宝没点，根因是模板只认粗体标签

**现象**：第二局关闭存档面板后，本该点传家宝 NPC，结果一直零输入，约 16 秒后以"误开选关页"退出。

**根因**（用真实帧 f0705–f0710 离线复现）：
1. 广场上鼠标悬停的那个 NPC 标签渲染成**粗体**，另一个是**细体**。`assets/Images/chuanjiabao.png` 只有粗体版本。
2. 第二局鼠标停在"存档挑战"上，"传家宝挑战"是细体：粗体模板在真实标签上只有 0.45–0.57，最高分反而打在"存档挑战"上（0.573）。所以 `_find_post_game_hub_entry("heirloom")` 返回 None，广场一直分类不成 NPC_HUB。
3. 同一帧 `_find_stage_page` 误判为真（f0707 真、f0708 假，不稳定），于是走"hitch 误开选关/游戏大厅"退出。
4. **b66f1ce 的过渡块治标不治本**：它挡住了第 3 步，但入口查找用的是同一个模板，在真实帧上只会零输入等到 300 秒总预算耗尽。它的单测把 `_post_game_hub_entry_click` mock 掉了，所以是假绿。
5. 旁证：09-13 21:17 那个证据包的 f1192–f1198 也是细体标签（粗体模板 0.45）→ 上一轮实机同样漏过传家宝。

**修复（63d351d）**：
- 新增 `assets/Images/chuanjiabao_thin.png`（从 f0707 裁出，已登记到 runtime_asset_manifest）。在 3 个证据包的 152 张广场帧上：细体标签 0.83–1.00，其他位置 ≤ 0.53，0.58 阈值两侧没有落在中间的帧。
- 修复后离线重放：f0706/f0707/f0708 全部分类为 NPC_HUB，并点击 OpenHeirloomChallenges @ (1073, 274)；第一局的粗体帧 f0346 行为不变。
