## 1. 识别任务五大类型分类法

| 类型代号 | 类型名称 | 核心判定原则 | 典型场景 | 推荐主检测器 |
| :--- | :--- | :--- | :--- | :--- |
| **TYPE A** | **OCR_REQUIRED** | 业务逻辑**必须精确获取多变文本内容**（技能名、未知卡名、特定数值） | 技能三选一 (G面板)、无模板新羁绊 | ROI紧裁 + Gray_2x + PP-OCRv5 + 词典归一化 |
| **TYPE B** | **CATEGORY_ONLY** | 画面有文字/图案，但业务**仅需判定所属大类**（如“是龙珠就拿”、“是Boss就打”） | 龙珠捡取 (1-7星)、Boss头像分类 | ROI + 色相/轮廓/紧凑模板库，**禁用通用OCR** |
| **TYPE C** | **VISUAL_SIGNATURE** | 业务只需检测颜色、发光、几何形状或稀有度徽章 | 提前挑战绿灯、自动开关、宝物稀有度 | ROI + HSV色彩阈值 + 连通域面积分析 |
| **TYPE D** | **UI_STATE** | 业务只需确认弹窗/按钮是否存在、界面是否切换、状态机推进 | 准备/开始游戏、失败确认、暂停遮罩 | ROI + 关键像素/二值模板/几何特征门禁 |
| **TYPE E** | **TEMPLATE_LAST_RESORT** | 色彩/几何/OCR均失效时的极小型局部字形兜底 | 羁绊标题艺术字短码 (~44x24字形) | 单通道局部 matchTemplate (严格限数量与用途) |
