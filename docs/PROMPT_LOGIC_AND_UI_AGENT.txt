# 已核实结论（改代码前必须承认）

## 1) 房间进游戏卡点
- 高发卡死日志：**「等待进入游戏UI」** → 超时 **「未找到关卡/主线UI,未找到位置」**
- 超时时间 ≈ Settings.QueryTimeOut（默认 120 秒）
- 含义：脚本在等 **选关/主线界面**，不是「房间里站着就行」
- 房间界面（成员+开始游戏）≠ 选关界面（1-3…地图列表）
- 成功样例：等 UI 约 1 分钟后出现「开始主线！」
- 失败样例（16:25）：从房间重开后直接「等待进入游戏UI」120s 失败
- 本地 mediator：PREPARE 点 start 模板 → WAIT_UI 点 stage 模板；**无独立房间状态机**
- 修复方向（若做本地）：
  a. 区分 ROOM / STAGE_SELECT / IN_GAME 三态
  b. 房间专用模板或 OCR「开始游戏」
  c. window_title_contains 锁窗，禁止全屏误匹配
  d. 文档提示：先 1600×900，或人先点进选关再开脚本

## 2) 技能不是中文的原因
- 官方 Settings.json 里 Skills 就是 ["asj","asjg","assx","jq"] 短码
- assets/Images/skills/*.png 文件名也是短码，**没有中文资源被同步**
- Skill.CnName 在 exe 类型里存在，但未写入用户配置文件
- UI 若要中文：新建 config/skill_labels.json 映射（需游戏内对照或用户标注），找图仍用短码

## 3) 关卡逻辑
- Stage1 + Stage2 = 官方 UI「目标关卡 A — B」两个数字框
- SGZXBoss = 主线/地图 Boss 下拉（boss/ 目录 stem）
- CJBBoss = 传家宝 Boss（chuanjiaobao/ stem）
- 局内「锚点BOSS名称」是运行时识别结果，可与设置 Boss 不同

## 4) 声望逻辑
- AutoReputation 总开关
- ReputationStage1/2、ReputationCJBBoss/ReputationSGZXBoss 与常规 Stage/Boss **平行配置**
- 官方：可领声望时走声望目标，否则常规；赌木不触发声望
- 本地 mediator **几乎未实现声望分支**，UI 开关目前主要是存盘展示
