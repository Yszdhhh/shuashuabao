# CORE-03 Shell 交接（2026-08-16）

## 看板入口

- 首屏只保留「单人刷图」与「蹭车 / 跟车」两个大型入口；选中后首屏隐藏，通过底栏「切换运行方式」返回，不再在看板上方来回切换。
- 蹭车默认进入大厅找房页，可在页内切换为已在房间跟车。所有 `live_enabled=false` 模式仍由 `RunnerService` 拒绝，按钮显示「待验证 · 不可启动」，不会创建 Runner/Mediator。

## 单人与测试配置

- 单人页面持久化自动创房、房名、密码（掩码输入）、每局新建/复用、关卡、局数、英雄阵营/难度、秘境与学习模式。
- 单人页优先显示「主线」与「关卡」：旧世界大陆（一阶段）、熔火之心（二阶段）、黑翼之潮（三阶段）、安琪拉（四阶段）。原始 `1-12` 目标字段、关卡难度和房间细节默认隐藏；秘境单独换行，勾选后显示其当前默认路线说明。
- 默认保留原房继续；房间详情、技能格、自定义搭配、基础羁绊、赌木都折叠。属性线改为可多选；必拿宝物与木材阈值等后台逻辑不再展示。
- `config/dashboard_test_profiles.json` 提供 V0 单局、V1 两局和秘境一局。导入仅允许 `normal_farm` 的看板白名单字段，且必须恰好一个处于当前主线范围的“章节-关卡”；未知版本、未知字段、范围越界和路径/命令/密码字段一律拒绝。
- 测试配置不含也不改 `dry_run`，导出不含 `room_password` 且使用同目录 `.tmp` 后 replace。应用前显示差异确认，应用后仅更新表单，绝不启动运行；内置配置缺失、损坏或非法时看板显示“内置方案不可用”，但仍可启动。

## 运行边界

- 本轮不创建桌面快捷方式、不运行真机。看板入口仍为仓库根目录 `desktop_app.py`。
- 用户设置继续写入 `%LOCALAPPDATA%\ShuaBao\user_settings.json`，使用同目录 `.tmp` 后 replace 的原子写入。
- `_shell.selected_mode_id` 会恢复；未知值回退 `normal_farm`，已保存的禁用模式仍受 Runner 门禁阻断。
