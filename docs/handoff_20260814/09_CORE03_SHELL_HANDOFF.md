# CORE-03 Shell 交接（2026-08-16）

## 看板入口

- 首屏只保留「单人刷图」与「蹭车 / 跟车」两个大型入口；选中后首屏隐藏，通过底栏「切换运行方式」返回，不再在看板上方来回切换。
- 蹭车默认进入大厅找房页，可在页内切换为已在房间跟车。所有 `live_enabled=false` 模式仍由 `RunnerService` 拒绝，按钮显示「待验证 · 不可启动」，不会创建 Runner/Mediator。

## 单人与测试配置

- 单人页面持久化自动创房、房名、密码（掩码输入）、每局新建/复用、关卡、局数、英雄阵营/难度、秘境与学习模式。
- 单人页主线/关卡旁常驻显示「模式」（普通 / 英雄）与「局数」（0–999，0 显示“手动停”）；普通模式隐藏阵营与英雄难度，英雄模式展开显示；从 user_settings 加载真实反映并在收集时正确写回。原始 `1-12` 目标字段和房间细节默认隐藏；秘境单独换行，勾选后显示其当前默认路线说明。
- 默认保留原房继续；房间详情、技能格、自定义搭配、基础羁绊、赌木都折叠。属性线改为可多选；必拿宝物与木材阈值等后台逻辑不再展示。
- `config/dashboard_test_profiles.json` 提供 V0 单局闭环（普通模式）、V1 两局和秘境一局。V0 完整配置 4 技能（奥数箭/奥数射线/剑气/冰霜新星）、8 羁绊（祝福/成长/体术/力量/屠戮者/智力/湮灭者/法术）与清空负面宝物放行名单 `treasure_allow_negative: []`。
- 导入仅允许 `normal_farm` 的看板白名单字段，`treasure_allow_negative` 仅允许空数组 `[]`，非空一律拒绝；未知版本、未知字段、范围越界和路径/命令/密码/dry_run 字段一律拒绝。
- 测试配置不含也不改 `dry_run`（学习模式），导出不含 `room_password` 且使用同目录 `.tmp` 后 replace。应用前显示差异确认，应用后仅更新表单，绝不启动运行；内置配置缺失、损坏或非法时看板显示“内置方案不可用”，但仍可启动。

## 运行边界

- 本轮不创建桌面快捷方式、不运行真机。看板入口仍为仓库根目录 `desktop_app.py`。
- 用户设置继续写入 `%LOCALAPPDATA%\ShuaBao\user_settings.json`，使用同目录 `.tmp` 后 replace 的原子写入。
- `_shell.selected_mode_id` 会恢复；未知值回退 `normal_farm`，已保存的禁用模式仍受 Runner 门禁阻断。
