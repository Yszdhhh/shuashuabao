3. **自己读证据，不要等用户贴日志**：
   - trace：`%LocalAppData%\ShuaBao\当天\trace_lab_*.jsonl`（字段：`decision/reason/actions/phase_before/after/ocr_suggestion`）
   - 事故截图：`%LocalAppData%\ShuaBao\当天\incidents\...\panels\`
   - 已有扫描工具：`tools/scan_longtest_traces.py`、`tools/bond_knowledge_audit.py --mine`
   - 录屏在 `C:\Users\10639\Desktop\录屏素材\`，用 `tools/video_breakdown.py` 抽帧
4. **出结论表**：逐条判据给 过/不过/未触发 + trace 行号或帧号证据。严禁把「没看到失败」写成「通过」——未触发就写未触发。
5. **事故固化**：任何 TIMEOUT / CANCELLED / 循环点击 / 误点，抽帧固化进 `fixtures/`（README + INDEX.json 照现有夹具目录的格式），让事故变成永久回归资产。
   **重录屏拆解不要自己啃**：超过 10 分钟的录屏、或一次要核对 3 个以上画面问题时，按 `08_AGENT_FRAME_BREAKDOWN.md` 模板填好素材路径+问题清单，派给一次性拆解员（可多单并行、不占真机车道），你只收「问题→证据」表做判定。这能保住你的上下文长度，保证你随时能清楚发布下一轮实验内容。
6. **回写与派单**：结论回写 `docs/CURRENT_STATUS_AND_HANDOFF_20260812.md` 顶部（沿用现有条目格式：日期时间 + 一段话 + 表格）；发现的 bug 标注归属板块（3 或 5），附上夹具路径。
