#### (6) 羁绊体系（S5 原文，修正"三国流"描述）
- 基础：成长（每秒 0.2 木 0.1 杀敌）；经济-挑战（每秒 0.4 木，加快挑战时间与数量）；力量/智力/敏捷（每秒 0.2 杀敌 0.1）。
- **体术-战术-生命-血誓-血魔 + 坚守-陷阵 = 体术系 T0 羁绊**（伤害增幅极高，搭配任意大羁绊）。
- **三国**：红卡杀敌 0.3，**魏=智力、蜀=敏捷、吴=力量、群=攻击**；任意三个国家各 9 张卡变红 → 羁绊"吞噬卡牌 1% 全属性增幅"。（原报告"三国体系（除刘备外）"无来源，已按原文替换）
- 亡灵：智力最强卡组（S17）；修仙：橙色杀敌全属性 0.1，大成 0.3，N9 才出 EX 0.4。
- 推荐开荒大羁绊顺序（S17）：**体术→成长→经济→封神→三国→异火→亡灵**；高难（N15-18）路线：亡灵海盗为核心，海盗→三国→异火→军团（S2 进阶帖）。

#### (8) 组队与辅助玩法（S13、S5）
- **压力转移**：进游戏 20 秒内装备栏上方按钮，过时消失；其他楼层怪物给一楼，一楼刷怪量↑怪物属性变。
- 辅助 9 点核心操作（S13）：开局立刻开压力转移、给符、拿敏捷箭术羁绊帮主 C 破甲（灭世斩：攻击 10% 概率永久移除目标当前 2% 护甲）等。
- 蹭车策略：官方玩家社群找氪佬发车，混车时主线不开/后开（S17、S13）。

#### (9) 挑战奖励与推荐进入时机（S17、S12）
- 混车：**主线先不开，挑战开完，宝物选好魔瓶后无限拿符**，主线根据主 C 进度开（主 C 到 2-6 可开到 2-4）。
- 单通：开局先开挑战与主线；天雷 1-11 单通流畅；难度越高解锁更多卡组选择。

#### (10) UI/显示与版本相关
- 官方说明（S1）：**如遇显示异常，将画面比例设为 16:9（或推荐 1920×1080）**——与脚本 `window_size=[1600,900]`、`window_title_contains=英雄三国` 直接相关（见 §二）。
- 已核实地图版本号 **1.1.89**（S3，2026-04-10 时点）；社区可见 1.1.0（S5，2026-02-04）。
- 3DM 官方宣传（S7，2026-04-08）：抽羁绊、集羁绊、吞噬进化、宝物万千、多系英雄转生、随机事件、全屏技能割草——与上述机制互证。

### 11. 与首版的差异清单（审查修正记录）
1. 奥术箭技能名与升级顺序修正（S3）。
2. 七星龙渊合成路径修正：黑市 3 级起无名之剑→杀敌进化→黑市 5 级寒冰碎片（S14/S16）。
3. 三国羁绊机制替换无来源的"除刘备外"说法（S5）。

## 三、脚本后续改造与优化建议（按投入产出排序）

### 1. 赌木模式 2.0（最高优先级，社区机制最成熟）
- **现状**：仅 `treasure_num` 配置，无判定逻辑。
- **建议**：按 S12 实现——2000 木起赌 → 识别目标宝物（登神/大炮/杀敌属性 EX 卡）→ 命中锁定并暂停通知 → 未命中刷新耗尽则 ZS 重开。需新增 `gambling_targets` 宝物图鉴与 OCR 词典条目。
- **ponytail**: 宝物模板先做登神/混乱转换 2 个目标，扩展时再补全图鉴。

### 2. 动态流派预设
- **建议**：UI 增加流派下拉：奥术箭（默认 `asj,asjg,assx,jq` + 增伤开关）/ 天雷 / 剑气 / 普攻 / 异火地震；后端 `/api/presets/skill-builds`。短码映射基于 S3/S4/S2 攻略。

### 3. 智能"卡关沉淀/扫荡"闭环
- **建议**：连续 2 局指定关卡失败/超时 → 自动回退至 `stage1-stage2` 低区间挂机 N 局 → 重试高关卡；进层判断可参考 S4 三条件（登神+宝物次数+羁绊完成度），但脚本侧可行替代是"通关时间/失败计数"启发式。
- **ponytail**: 三条件需要游戏内状态识别（文本/图标），先做计数启发式，OCR 成熟后再升级。

### 4. 隐藏成就/合成自动介入
- **建议**：七星龙渊：检测黑市 3 级+ → 买无名之剑 → 杀敌数达标后 5 级黑市买寒冰碎片合成；龙珠 7 颗收集满后触发许愿保护。军团/远古神器合成按 S16 材料清单做背包检测。

### 5. 黑市购买模块
- **建议**：按 S4 优先级清单实现顺序购买（英雄刷新→宝物刷新→宝物→献祭→属性→吞噬丹→伐木机→无名剑→升级黑市）；杀敌投资在 58 秒窗口购买（需时钟对齐游戏内时间，先手动标注可行性）。

### 6. 背包自动清理增强
- **现状**：`auto_clean_interval=5` 局数触发。
- **建议**：增加"只分解紫品及以下""防分解锁定（UR/传家宝）"分支；对应 S2 刷装备帖的宝石词条优先级（绝世＞技能专属＞暴击＞boss 增伤）可作分解/合成决策输入。

### 7. 数据标注与 OCR 词典素材
- 本报告来源可直接用于：规则初始化（流派技能序）、模板资产（黑市/宝物/羁绊图标定位）、OCR 词典（Boss 名：暴掠龙/巨形缝合怪/血神哈卡/玛格曼达/赞吉尔；技能：奥术箭/急速抽箭/爆炎箭/天雷/闪电链；宝物：登神长阶/混乱三围/水桶腰/智之极/无名之剑/寒冰碎片）。
- **不直接用于模型训练**：社区攻略文本含大量口语与"水贴"回复（S3 评论区可见），需清洗；数值（CD/伤害）以游戏内为准。

### 6.3 对报告结论的补充与修正
1. **作者网络确认**：奥术箭/天雷/大秘境三大核心攻略的图文与视频出自同一批人（夙愿、风轻语、泡泡茶壶系），社区图文与抖音视频可互相印证，整体可信度上调。
2. **黑话词典扩充**（源自抖音标题/搜索词）：欧米茄（=S4 必备英雄）、永辉者、憋英雄（攒卡操作）、双雷流、刷装、坐车（=S13 混车）、免肝速成（代肝）。其中"双雷流"在 KK 图文攻略中未单独成篇，仅在抖音成体系——**是图文检索漏掉、抖音独有的流派信息**。
3. **视频级标注仍是短板**：抖音视频无公开时间戳/章节，未做逐帧核对；若要用作训练 fixture，需本地下载后人工/半自动标注（可纳入后续管线）。
4. **版本实时性**：抖音创作者持续更新（无胆超人 3 天前、小北 7 小时前仍有发布），比 KK 社区帖更新快，适合监测版本变更与 UI 改版；但短视频易过时，引用须核对发布时间。
