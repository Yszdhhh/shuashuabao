## 1. 结论

本次核查纠正了 99.48% 的口径：该数字不是冻结裁剪规则后的新 episode 盲测，而是 O1 的标签辅助逐样本紧裁（155 槽，含 SKILL-FIX 重新校准的 6 槽）与 D0 rec9/rec10 候选槽混合评测后的结果。最新 O3 产物显示 388 槽中 1 个 unknown 不进分母，因此报告分母为 387，Top-1 为 385/387 = 99.48%。

当前不存在可作为门禁证据的盲测槽：

- D0 rec9/rec10 的 97 个 panel episode、233 个有效槽全部已进入 O3 387 槽，和 O3 在 **session 级**重叠；
- D0 源帧是 1920×1080 全桌面录屏，不能冒充 1600×900 游戏窗口；
- D0 的 bbox 是 OCR 检测框，truth 是 OCR+词典建议/复核落库，不是冻结规则后独立标注；
- 新盲测 fixture 当前 `entries=[]`，因此盲测 Top-1、skill recall、误归一均为 **N/A（0 槽，未运行）**，不是 0% 或 PASS。

结论：99.48% 继续保留为“标签辅助训练侧证据”；OCR 盲测门禁保持未通过/未具备证据，直到新的、未出现在 O3 387 槽中的 1600×900 session 完成冻结裁剪与独立 truth 标注。

## 4. 冻结裁剪规则

规则只允许依照布局先验和三槽 x 分带生成 crop；**不得**依据当前帧检测框、truth、OCR 结果或标签回调修正。归一化坐标如下：

| kind | name y 带 | 依据 |
|---|---|---|
| skill | 0.160–0.250 | O1 跨 session 中位数 y0 ≈ 0.174 |
| bond | 0.250–0.350 | O1 跨 session 中位数 y0 ≈ 0.270 |
| treasure | 0.170–0.270 | O1 跨 session 中位数 y0 ≈ 0.186 |

三槽 x 分带固定为 `[(0.230,0.400), (0.415,0.585), (0.600,0.770)]`；progress 固定 y 带为 `0.360–0.450`。所有规则位于 `tools/crop_ocr_choices.py:frozen_roi_for_slot()`，blind audit 会输出同一规则。

盲测 entry 还必须满足：

1. frame/window 实际分辨率为 `[1600,900]`，不是 1920×1080 全桌面截图、缩放或伪造；
2. `session_id` 不属于 O3 现有 9 个 session（session 级隔离，不接受同 session 抽子集）；
3. truth_source 为 `independent_manual` 或 `independent_double_annotation`；
4. episode 级去重：同一面板静止期只保留一个主样本。

## 8. action ledger、风险与回滚

- action ledger：本修复新增的 blind audit 和冻结 crop helper 均为离线分析；生产输入路径差异 **0**；没有鼠标/键盘/点击动作。
- 主要风险：若未来把 rec9/rec10 子集直接填入 `entries`，audit 会按 session overlap 拒绝；不要删除该保护。
- 主要风险：D0 truth 是 OCR+词典建议，即使视觉复核落库，也不能追溯成冻结规则后的独立标签；正式盲测必须换独立标注。
- 主要风险：1920×1080 全桌面截图中游戏窗口坐标会漂移；必须先记录真实 1600×900 窗口边界，禁止按比例缩放伪造。
- 回滚：删除 `frozen_roi_for_slot()`、`--blind` 分支及 `o3_blind_manifest.json` 即可恢复原普通 O3 评测；不涉及生产代码迁移。
