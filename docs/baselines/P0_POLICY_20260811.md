## 3. 实现摘要

### 3.1 输入契约（全部显式传入，无读屏/点击/隐式全局状态/时钟依赖）

```python
PanelCandidates{
  panel_kind: "skill" | "bond" | "treasure" | None,   # None → NONE（无面板）
  slots: [SlotCandidate{index:int, name:str|None, confidence:float,
                        evidence:str, rarity:str|None}],  # name=None 即 unknown
  set_progress: {set_name: {have:int, need:int,
                            members:[名称...], owned:[已拥有名称...]}} | None,
  refresh_count: int,        # 识别层可验证的本面板已刷新次数（session 缺省时兜底）
  has_giveup: bool,          # 面板存在放弃按钮（识别层可验证）
  settings: {skill_presets:[...], bond_presets:[...], treasure_presets:[...],
             quality_order:[...], min_confidence:float}
}
SessionState{   # 本次 panel episode 会话记账（执行层维护；WAIT 不计入 attempts）
  attempts:int, refreshes:int, waits:int, deadline_exceeded:bool,
  max_attempts:int=12, max_refreshes:int=3, max_waits:int=5
}
```

### 3.2 输出契约

```python
PolicyDecision{ action: PolicyAction, index: int | None, reason: str }
PolicyAction = SELECT_SLOT(index) | REFRESH | GIVEUP | CLOSE | WAIT | NONE
```

执行层只消费 `action` + `index`（槽位编号，绝无像素坐标/原始文本）；`reason` 供 trace 还原「候选→规则→动作→后置确认」。

### 3.3 决策规则表（蓝图 §12 全文落地）

| 面板 | 优先级顺序 | 规则 | 动作 |
|---|---|---|---|
| **技能** | 1 | 槽位 name ∈ skill_presets（按用户配置顺序；同预设多槽取最小 index） | `SELECT_SLOT(index)` |
| | 2 | 预设未命中（含全部槽位 unknown）→ 已刷新 < max_refreshes | `REFRESH` |
| | 3 | 刷新耗尽 → has_giveup | `GIVEUP` |
| | 3' | 刷新耗尽且无放弃按钮 | `CLOSE` |
| | — | **永不返回非预设技能槽**（SELECT 仅在 name ∈ presets 时发生） | — |
| **羁绊** | 1 | name ∈ bond_presets（配置顺序 + index 升序 tie-break） | `SELECT_SLOT` |
| | 2 | 接近合成：`gap = need - have ∈ [1,2]` 最小者；需 `members` + `owned` 可验证（缺 owned 即证明不了缺哪张 → 跳过，绝不猜测）；只选 `name ∈ members - owned` | `SELECT_SLOT` |
| | 3 | 品质降级：quality_order rank 最小（缺失/未知品质带排最末）；仅词典内规范名（name 非空）且 confidence ≥ min_confidence | `SELECT_SLOT` |
| | 4 | 无安全候选：WAIT < max_waits 且刷新可用 | `WAIT` |
| | 5 | WAIT 耗尽 | `REFRESH` |
| | 6 | 刷新耗尽 | `GIVEUP` / `CLOSE` |
| **宝物** | 1 | name ∈ treasure_presets | `SELECT_SLOT` |
| | 2 | 套装进度优先（龙珠等：members/owned 来自可验证字段；规则同羁绊合成） | `SELECT_SLOT` |
| | 3 | 品质降级（同上） | `SELECT_SLOT` |
| | 4–6 | 无安全候选：WAIT → REFRESH → GIVEUP/CLOSE（禁止无限等待） | — |
| **任意** | 抢占 | `deadline_exceeded`（外部时钟判定）或 `attempts ≥ max_attempts` → 立即放弃/关闭 | `GIVEUP`/`CLOSE` |
| 无面板 | — | `panel_kind=None` | `NONE` |

同帧多面板：`panel_priority(kinds)` 纯函数返回技能 > 羁绊 > 宝物（技能学习优先于羁绊/宝物循环），集成波按序逐面板调用。

### 3.4 确定性保证

- 纯函数：无 I/O、无随机、无时钟；模块级常量不可变；
- 并列 tie-break 全固定：配置顺序（用户顺序有意义）→ 槽位 index 升序 → set 名字典序；
- 槽位乱序、set_progress dict 插入顺序不同、settings 以 dict 或 PolicySettings 传入 → 结果一致（有测试证明）；
- 合法输入必然终止：WAIT 有 `max_waits` 上限，之后 REFRESH → GIVEUP/CLOSE，无任何无限等待路径。
