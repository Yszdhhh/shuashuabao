# O4 OCR Shadow Sidecar — 2026-08-11

## 1. 结论

O4 独立 shadow 模块已实现，未接入 `mediator.py`。主进程只导入 JSONL/client 协议和图像编码代码；Paddle/PaddleOCR 仅在 `.venv-ocr` 持久子进程中加载。返回值只有规范候选、置信度和耗时（不可用时为 `unavailable`），模块没有输入执行路径。

## 2. 文件

- `src/gamescript/vision/ocr_shadow/protocol.py`：JSONL 编解码、`ShadowResponse`、panel 内容指纹。
- `src/gamescript/vision/ocr_shadow/client.py`：常驻 `Popen`、顺序请求、心跳、超时、崩溃重启上限、面板指纹缓存、独立 shadow trace。
- `src/gamescript/vision/ocr_shadow/worker.py`：sidecar 入口；本地模型校验、ASCII staging、一次模型加载、归一化候选。
- `tools/ocr_sidecar_stress.py`：10,000 请求/三槽 P95/RSS/子进程/协议对齐压力工具。
- `tests/test_ocr_shadow.py`：协议往返、坏 JSON、超时、崩溃重启、缓存失效、模型缺失降级。

## 3. 协议

每条 stdin 请求一行 JSON；sidecar 每条 stdout 响应一行 JSON。客户端按 `seq` 严格匹配，服务进程按顺序处理。

```json
{
  "type": "predict",
  "seq": 12,
  "frame_ref": "1600x900:md5...",
  "session": "rec5_260808",
  "panel_id": "panel-42",
  "slot_id": 1,
  "id": "panel-42:1",
  "bbox": [640, 210, 920, 315],
  "kind": "skill",
  "image_b64": "<PNG crop>",
  "sent_at": 1786430000.12
}
```

可用响应：

```json
{"seq":12,"status":"ok","candidates":[{"name":"奥术增幅β","confidence":0.91}],"elapsed_ms":142.7}
```

不可用响应：

```json
{"seq":12,"status":"unavailable","candidates":[],"elapsed_ms":400.0,"reason":"timeout"}
```

`reason` 可为 `starting`、`timeout`、`bad_json`、`crash`、`model_missing`、`model_corrupt` 或 `inference_error`。坏 JSON、超时和子进程 EOF 会杀掉当前管道；下一请求使用新管道，避免迟到响应造成协议错位。连续崩溃达到 `max_restarts`（默认 3）后，本次 session shadow 禁用；`reset()` 可显式开启新 session。

## 4. 模型与离线行为

worker 只读取 `models/ocr/PP-OCRv5_mobile_rec_infer`，启动前校验 manifest 中的文件大小/SHA-256，并复制到 ASCII 临时目录以满足 Windows Paddle loader 限制。不存在、损坏、无法加载的模型不会传播异常；worker 保持 JSONL 服务并对每个预测返回 `unavailable`。主进程不 import `paddle`，也不发起下载。

## 5. 缓存与 shadow 边界

缓存结构为 `panel_id -> (panel_fingerprint, slot+bbox+kind -> ShadowResponse)`。新 fingerprint 会立即清空该 panel 的旧槽结果；面板缓存最多 256 个 panel，避免画面轮换导致增长。缓存只返回候选，永不授予动作授权。`ShadowClient` 仅写可选的独立 JSONL trace（`trace_path`），包含 fingerprint、bbox、状态、候选、耗时和 `cache_hit`。

## 6. 接线接口

集成波使用：

```python
from gamescript.vision.ocr_shadow import ShadowClient

client = ShadowClient(timeout_ms=400, trace_path="logs/ocr_shadow.jsonl")
response = client.shadow_predict(
    frame,
    panel_id,
    {"slot_id": slot.index, "bbox": slot.bbox, "kind": panel_kind},
    session=session_id,
    panel_bbox=panel_bbox,
)
# response.status == "ok" 时读取 response.candidates；不产生任何输入动作。
```

也提供 `shadow_predict(frame, panel_id, slot, client=client)` facade。集成方负责在强面板锚点成立且模板低置信/unknown 时调用；普通 tick 不调用。模板决策和 action ledger 仍是唯一动作来源。

## 8. ledger 与风险

本波只新增独立 OCR runtime、压力工具、单测和本 baseline 文档；没有修改 `mediator.py`、场景、设置、输入执行器或 action ledger。OCR 结果只能进入 shadow trace；接线波必须继续保持 off/shadow 与模板 action ledger 等价，并在首次模型 warmup 时把 `starting` 当作 unavailable。
