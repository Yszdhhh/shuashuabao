1. **显式 per-slot bbox**：52 面板 × 155 有效槽全部取得显式归一化 bbox（6 个 designer

   skill 卡名 y0≈0.174 / bond y0≈0.27 / treasure y0≈0.186（跨 session 中位数稳定）。

   卡名在 y≈0.19-0.24 → 1.45% 的根因是裁剪错位而非模型（紧裁后 光法 0.9999、焦点 0.99）。
3. **unknown 布局**：manifest 无显式 bbox 的槽位标 unverified_layout 且不裁剪；
   本批 155/155 verified、0 unverified_layout。
4. **truth 对齐**：19 个非规范 truth —— 2 个 奥术激光→奥数激光（别名纠正）；
   17 个标 unknown（不进准确率分母，需 O2 词典核实）。
