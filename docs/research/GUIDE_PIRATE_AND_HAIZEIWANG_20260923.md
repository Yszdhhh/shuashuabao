## 2. 海贼王链路（全 guide_external）

| 卡 | 品级 | 效果摘要（外部原文压缩） |

| 见习海贼 | N | 三属性+50；开池 |

| 凯多 | UR | 攻/甲；雷鸣八卦 AOE；站场 |
| 红发 | UR | 全属+300；神避爆发+无敌帧 |
| 白胡子 | UR | 三最终+8%；震动 AOE+眩晕 |
| 大妈 | UR | 火雷+杀敌叠属性 |
