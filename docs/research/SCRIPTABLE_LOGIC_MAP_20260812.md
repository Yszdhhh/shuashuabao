## 双权重如何进决策（改造方向）

```text
观测槽位 (OCR/模板)
  → 官方权重包（presets / negative / quality_order）【订阅/正版】
  → 用户习惯权重（本地 preference）【免订阅，只调允许集合内优先级】
  → choice_policy 纯函数
  → Mediator 唯一调度 → InputExecutor
```

硬约束（习惯权重不得突破）：

1. 技能：不得选出官方/用户预设之外的技能  
2. 羁绊：不得突破 hard whitelist  
3. 宝物：不得默认放行负面名单  
4. 大厅红线、UNKNOWN 零输入不变
