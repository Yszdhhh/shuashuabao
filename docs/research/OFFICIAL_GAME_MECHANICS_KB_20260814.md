## 4. 机制分节（帮助页原文整理）

### 4.1 热键与面板

- **F**：羁绊抽卡，耗木头。集齐自动吞噬。
- **G**：技能抽卡，耗技能点。官方建议同一技能点到最终形态。
- **C**：主线挑战。属性奖励 + 大量木头；主线 BOSS 另给材料。
- **F1**：操作切回自身英雄（防 G/V/F 面板无法操作）。`source=user_confirmed`（2026-08-14）。可作「面板无响应恢复焦点」候选，**接线另立项**。
- **F2**：回基地（视角偏离或要点秘境/传家宝点不到）。`source=user_confirmed`（2026-08-14）。未接。旧口述「两次 F2」作废。
- **专属升级**：耗金币；每 10 级选词条。热键未写。
- **资源挑战**：金币 / 木头 / 经验 / 宝物，各拿对应奖励。
- **奇遇**：击败 BOSS、击杀特定数量敌人、或完成主线后有几率触发。
- **提前挑战**：通关主线 **5-5** 且本局 ≥ **10 分钟**，按钮在左上。
- **技能卡牌查看**：存档 → 技能，右下放大镜看衍生卡。
- **F4**：清自己场上挑战怪（含压力转移送来的怪）。**打不过就按**；还打得过时禁止误按。未接线。

### 4.2 基础属性

- 生命 0 = 死亡失败；**免费复活 1 次**。
- 攻击力同时影响普攻和技能。
- 护甲减物理 **和** 魔法。
- 力量 1 点 = +0.3 攻击、+1 生命。
- 敏捷 1 点 = +0.3 攻击 + 物理伤害%（递减）。
- 智力 1 点 = +0.3 攻击 + 魔法伤害%（递减）。
- 攻击范围 = 攻击距离。
- 攻速上限 **1000%**。
- 多重/弹射：**不触发普攻特效**；伤害系数基础 30%、上限 100%。

递减公式、暴击倍率、命中公式：未知。

### 4.3 特殊属性与乘区

- 掉宝率：存档物品；关卡 BOSS 掉落处可看实际几率。
- 卡牌属性：抬羁绊卡数值；羁绊卡属性算**白字基础属性**。
- 存档颜色：白=基础（装备套装/词条/强化/特质 + 羁绊卡）；绿=增益。
- 致命一击：概率提高伤害倍数。
- 穿透次数：部分技能多穿几个目标。
- 命中 / 闪避：闪避覆盖真伤。
- 技能急速：CDR，上限 **80%**。
- 所有伤害、伤害增幅：**独立乘区**。最终伤害在最后阶段。
- 附加伤害：加在原数值上，**不额外跳字**（防卡顿）。
- 格挡：最后结算减固定伤害。
- 护甲穿透：无视固定护甲。

### 4.4 状态效果（两页合并，圣盾用页2）

| 状态 | 效果 |
|---|---|
| 眩晕 / 冻结 / 麻痹 | 无法行动 |
| 燃烧 | 每秒 100% 攻击 **[火系]物理**；吃「燃烧伤害」 |
| 燃霜 | 每秒 200% 攻击 **[火系]物理**；火抗 -10%；最多 3 层；吃燃烧伤害 |
| 冰焰 | 每秒 200% 攻击 **自适应**；每层火/冰抗 -6%，火冰受伤 +3%；最多 5 层；吃燃烧+冻伤 |
| 冻伤 | 每秒 50% 攻击 **[冰系]魔法**；移速 -10%；最多 5 层；吃冻伤伤害 |
| 感电 | 受伤时附加 25% 全属性到**本次伤害基础系数**（不跳字）；电系受伤 +10% |
| 减速 | 移速 -30% |
| 重创 | 受伤 +20% |
| 瓦解 | 受伤 +25% |
| 衰弱 | 移速 -80% |
| 易伤 | 受伤 +20% |
| 破甲 | 护甲 -10% |
| 圣盾 | 每层抵消 1 次伤害 |

重创/瓦解/易伤是否互叠、持续时间：未知。

### 4.5 伤害与触发

- **自适应**：元素取最高系；物理/魔法取较高；若算技能伤害则吃技能伤害。
- **附加系数**：加算到技能原系数。`50% 攻击 + 10% 敏捷`；再加 `10% 攻击` → `60% 攻击`。
- **普攻触发**：只有普通攻击命中。
- **主技能触发**：只有初始技能原形态。次级箭 / 小冰箭 / 磁暴不算。剑气、龙卷风等多段每次都算。
- **怪物强度**：血量、防御、攻击**等比**涨。

### 4.6 卡池

- 衍生卡：必须拿到**全部**前置技能才进池。
- 排斥不对称：审判之雷 → 排斥磁暴；磁暴 ↛ 审判之雷。其它不对称对：未知。
- 已吞噬：不能再进化。
- 集齐羁绊：自动吞噬。

### 4.7 多人

- **压力转移**：多人、1-1 后、非 1P 可见。取消多人刷怪加成。1P 得「携手同心」。准备阶段可把怪送到 1P。金币+杀敌 → 1P；挑战奖+经验+木头 → 发送方。1P 失败则转移方立刻失败。
- **携手同心**：每名转移队友 1 层，每层掉宝 +5%，最多 3 层（+15%）。

### 4.8 胜负

- 胜：时限内打掉最终 BOSS。
- 负：阵亡，或超时没打掉最终 BOSS。
- 生命 0 = 死；免费复活 1 次。`-zs` 清掉全部复活次数。
