# 《重生魔兽刷刷刷》全网游戏策略调研与脚本改造建议

> **文档定位**：汇集 KK 对战平台热门 RPG 地图《重生魔兽刷刷刷》全网（贴吧、B站、社区、论坛等）玩家攻略、主流流派、隐藏成就及进阶技巧，结合 `GameScript-Local` 当前脚本架构，分析可直接应用或后续参考改造的功能点。

---

## 一、 全网核心策略与玩家经验汇总

### 1. 三大主流流派与构筑

| 流派名称 | 定位/难度 | 核心技能/卡牌 | 优势与适应场景 |
| :--- | :--- | :--- | :--- |
| **奥术箭流** | **T0 级平民之神** (低门槛高上限) | `奥术箭` + `急速抽箭` + `奥数增伤` + `爆炸箭矢` | 零氪与高难（如 N16）首选。通过技能急速（CD 缩减）和奥术增伤加成压极限冷却，清屏与单体伤害兼备。 |
| **天雷流** | **高频清屏刷图流** | 主堆智力/魔法伤害，配电系/雷暴技能与电属性宝石 | 高频率触发雷暴效果，适合大规模怪物割草与快速刷图，需要一定智力基础与宝石支撑。 |
| **三国/亡灵吞噬流** | **中后期战力膨胀流** | 三国体系（除刘备外）、亡灵羁绊印记（邪灵引爆） | 依靠吞噬机制与羁绊叠加，后期属性膨胀极快。避免混搭海盗等占格羁绊。 |

---

### 2. 关键游戏机制与通关技巧

#### (1) 开局重开（ZS）与开荒节奏
- **ZS 重开机制**：开局抽取初始卡牌/指令（如四张令），若未拿到核心卡（如孙悟空/核心技能），高玩普遍选择直接 **ZS (自杀重开)**，以极低的成本追求完美开局。
- **开局福利与礼包**：新号/开荒期需第一时间使用兑换码领取初始资源与宠物（如虎王邦加拉什），并激活“时光共鸣”追赶机制。

#### (2) 赌木（木材资源博弈）
- **木材消耗**：木材用于抽取 EX 级宝物、珍藏品或高级技能/羁绊洗练。
- **赌木策略**：积攒固定数量木材后集中抽取第一个宝物。若抽中目标宝物（如赌木成功）则继续，若刷新次数耗尽未出则直接 ZS 重开，极大地缩短无效刷局时间。

#### (3) 隐藏成就与合成公式
1. **七星龙渊**：商店购买 `无名之剑` → 刷怪升至 `真·无名之剑` → 商店升至 5 级购买 `寒冰碎片` 组合解锁。
2. **祖龙 (我的山海界)**：收集 4 个 UR 稀有度神兽合成。
3. **兵主**：亡灵羁绊三种印记各≥10个，使用 `邪灵引爆` 或消耗 100 个疲迹解锁。
4. **我打不过呀**：凑齐七龙珠后在许愿/存档处有概率触发。

#### (4) 沉淀（考古/扫荡）机制
- **卡关应对**：当主线关卡或秘境 BOSS 回血太快/推不动时，盲目强刷效率极低。高效做法是回退至已通关关卡进行“沉淀”（刷考古币、声望与基础属性），提升装备与技能等级后再冲关。

## 二、 现有脚本功能 vs 全网策略映射分析

对比当前 `GameScript-Local` 项目的实际功能架构（参照 `config/default_settings.json` 及 `Help.plain.txt`）：

| 玩家游戏策略 / 需求 | 现有脚本功能实现 | 匹配度与现状分析 |
| :--- | :--- | :--- |
| **奥术箭流配置** | 默认技能组合：`asj, asjg, assx, jq` + 快捷开关 `aoshu_zengshang` | **高度匹配**：脚本内置了标准的 4 技能奥术箭图集与增伤开关。 |
| **开局 ZS 赌木** | 专有模式 `赌木模式`（开主线选第一个宝物，刷新 0 未找到则 ZS，找到暂停通知） | **高度匹配**：已实现完全自动化的赌木重开闭环。 |
| **卡关保护与战场清理** | `自动 F4` 开关（主线 5-5 自动清理怪物并关闭主线） | **匹配良好**：有效解决 5-5 阶段卡关与怪量堆积问题。 |
| **声望与副本扫荡** | `声望配置` (起止关卡、声望 Boss 下拉) + `邪修秘境` 独立模式 | **匹配良好**：具备基本的副本与声望自动挑战能力。 |
| **背包与资源清理** | `自动清理`（按指定局数自动分解装备/传家宝、合成宝石） | **基础实现**：满足基础防背包满溢需求，但缺防误清的智能逻辑。 |
| **沉淀扫荡循环** | 目前需手动修改目标关卡范围 `stage1` - `stage2` | **待优化**：缺少卡关自动回退“沉淀扫荡”的智能切换。 |
| **隐藏成就自动化** | 暂未针对 `七星龙渊`/`祖龙` 等多步骤购买组合提供自动化操作 | **待拓展**：属于高级定制化玩法。 |

## 三、 脚本后续改造与优化建议

基于全网策略调研与现有代码架构，建议从以下 6 个方向对脚本进行增强：

### 1. 赌木模式 2.0 (多目标与条件识别)
- **改进点**：现有的赌木模式检测到“赌木”宝物即暂停。
- **优化建议**：
  1. 支持宝物模板扩充（如识别特定 EX 宝物或 UR 卷轴）。
  2. 增加“自动继续”模式：抽到优质宝物后不暂停，而是自动切换为常规打图逻辑。

### 2. 动态流派预设 (奥术箭 / 天雷流 / 物理流)
- **改进点**：目前面板技能虽然可以勾选，但需要手动挑选图标短码。
- **优化建议**：
  1. 在 UI 界面增加“流派一键预设”下拉框：
     - **奥术箭流（默认 T0）**：自动勾选 `asj, asjg, assx, jq` + 开启 `奥数增伤`
     - **天雷流**：自动勾选雷系技能短码 + 开启智力属性优先
     - **物理敏捷流**：自动勾选攻速/破甲技能
  2. 后端 API 增加 `/api/presets/skill-builds` 响应，一键加载官方推荐构筑。

### 3. 智能“卡关沉淀/扫荡”闭环 (Smart Anti-Stuck & Farming)
- **改进点**：若玩家设置的高关卡（如 Stage 10）频繁超时或失败，当前脚本仅记录超时。
- **优化建议**：
  1. 引入失败计数器：若连续 2 局在指定关卡失败/超时，自动降低关卡范围（如退回 Stage 5-8 进行“沉淀挂机”）。
  2. 设定“沉淀局数”（例如挂机 10 局积累资源后），再尝试冲击原高难度关卡。

### 4. 隐藏成就/合成自动介入
- **改进点**：玩家需手动合成“七星龙渊”或“祖龙”。
- **优化建议**：
  1. 增加“合成助手”小模块：检测商店等级到达 5 级时，自动判定背包是否有 `真·无名之剑`，若有则自动购买 `寒冰碎片` 触发合成。
  2. 在七龙珠收集满后，自动触发“许愿/存档”保护，防止跳过隐藏成就。

### 5. 背包自动清理与防误清规则增强
- **改进点**：`自动清理`目前依赖局数触发。
- **优化建议**：
  1. 优化模板匹配：增加针对高阶传家宝、UR 装备的“防分解锁定标志”图像检测。
  2. 允许用户在 UI 上配置“只分解紫品及以下”、“自动合成高阶宝石”等具体分支开关。
