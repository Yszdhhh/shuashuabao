## 体系总览：五大核心分支与拿取优先级

```
【第 1 阶段：启动五件套 (Round 1)】
祝福(3) + 成长(4) + 经济(3) ──> 贪婪(3) + 挑战(3)  [提供前期属性滚雪球与资源吞噬]

         ├──> 【第 3 阶段：通用输出与爆发线 (暴击/大炮)】
         │      暴击(2) ──> 致命(2) ──> 大炮(2)  [暴击率>50%后质变拉满]

         ├──> 【第 4 阶段：攻防生存与破甲线 (提速/体术)】
         │      提速(3) ──> 体术(3, 破甲10%) ──> 固守(2) ──> 陷阵(2)
         │               └──> 生命(4) ──> 血势(3) / 血魔(3)

                ├── ⚡ 封神大道 (封神榜 / 打神鞭 / 斩仙飞刀) ── 真实天罚 + 金身

                └── 🧘 修仙九转 (修仙 / 筑基丹 / 金丹 / 元神) ── 全属性百分比飞升
```

## 六、引擎执行逻辑（选卡排序算法）

1. **吞噬紧急压制（Level 0）**：若背包仅剩 1 格且刷出「贪婪」，无视所有顺序**强行秒选贪婪**防爆仓。
2. **开局阶段（Level 1）**：严格锁定 `[祝福 -> 成长 -> 经济 -> 贪婪 -> 挑战]` 闭环。
3. **主路线激活（Level 2）**：
   - 若走 **奥术/法系**：优先锁定 `[急速 -> 智力属性链 -> 法术]`；
   - 若走 **物理/箭矢**：优先锁定 `[体术(破甲) -> 暴击 -> 致命 -> 大炮]`。
4. **特色流派成型（Level 3）**：当检测到用户开启了「封神/亡灵/修仙」偏好时，前置卡刷出直接锁定加权。
