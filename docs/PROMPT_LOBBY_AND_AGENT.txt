# 你必须先建立的分层模型（读完再改任何代码）

自动化分两层，禁止混为一谈：

L0 大厅/房间（Lobby-Room）
  - 创建房间、房间名/密码、等待成员、点击「开始游戏」
  - 官方方法痕迹：CreateRoom, BeginGame, LaunchGame, EntryF1, creatRoomNode
  - 模板极少：Images/startGameBtn.png, jihuo.png, continueGame.png（匹配常失败）
  - 本地 mediator.py：基本没有 L0 状态机
  - 官方帮助：独狼模式 =「自己点击房间开始游戏」；带队车头 = 自动开始、不主动点开始；
    房间名/密码/每局新房间 = 仅带队有效

L1 局内（In-Game，选关之后/战斗中）
  - 选关、选卡、技能、龙珠、锚点Boss、秘境、退出
  - 模板 90%+ 在 assets/Images/
  - 日志关键词：开始主线、卡都找完了、锚点BOSS、查找龙珠、QuitGame
  - 本地与多数 Agent 工作都集中在这一层

用户现状：GameMode=0 独狼，自己建好房间坐着，脚本在跑但不点开始。
这是 L0 缺口 + 独狼语义，不是 L1 选卡坏了。

# 日志如何判断卡在 L0 还是 L1
- 只有「等待进入游戏UI」→ 超时「未找到关卡/主线UI」= 卡在 L0→L1，人多半还在房间或分辨率不对
- 出现「开始主线」之后才是 L1
- 「已经准备游戏了」不等于已经点了房间开始并加载完
