 🔍 环境检测（必须）
 前置操作 
 
 
 每次使用程序前，必须先打开游戏，然后点击程序内的“环境检测”按钮 ，验证环境是否正常。`n环境检测通过后，方可进行后续设置与启动。`n若检测失败，请根据提示调整系统设置（缩放、分辨率、窗口化等）。`n⚠️ 重要： 跳过环境检测可能导致程序无法正常运行或出现未知错误。
 
 

 
 
 
 ⚙️ 窗口化 & 分辨率
 必须 
 
 
 游戏画面 必须设置为窗口化模式 （非全屏 / 无边框窗口）。`n游戏分辨率固定为 1600 × 900 （16:9）。`n电脑显示缩放 必须为 100% （系统设置 → 显示 → 缩放与布局）。`n⚠️ 不建议使用双屏 — 双屏会导致游戏 UI 大小异常（拉伸或压缩）。`n💡 检查方法： 右键桌面 → 显示设置 → 缩放与布局确认 100%；游戏内视频选项选择“窗口化”并设置分辨率 1600×900。
 
 

 
 
 
 ⌨️ OSK 键盘（屏幕键盘）
 赌木模式 · 强制 
 
 
 赌木模式 下 强制使用 Windows 自带 OSK 键盘（osk.exe）。`n其他模式 不强制 ，但 强烈建议使用 （英雄死亡后可能导致游戏内 UI 丢失，OSK 可保持输入稳定）。`n开启方式： Win+R 输入 osk 回车 ，或使用快捷键 Win+Ctrl+O 。`n⌨️ 推荐开启方式 
 Win + R 输入 osk 并回车 
 或 
 Win + Ctrl + O 
 ✅ 系统原生 · 无风险 
 
 
 ⚡ 为什么建议使用 OSK？ 游戏内输入框可能因英雄阵亡、界面重载而失去焦点，OSK 独立于游戏进程，确保连续操作。
 
 

 
 
 
 🎮 游戏模式 & 功能设置
 完整说明 
 

 

 
 📌 游戏模式`n独狼模式 
 单人 
 — 自己点击房间开始游戏，如果队友不卡游戏房间，也可以组队使用这个模式。
 `n带队模式（车头） 
 队长 
 — 会使用房间的自动开始功能，不会主动开始游戏。其他行为与独狼模式一致。
 
 🏷️ 房间名称 / 密码 / 每局新房间 （仅带队模式有效）：
 可自定义房间名称和密码，并支持 每局结束后自动建立新房间 ，避免重复手动创建。
 
 `n赌木模式 
 强制 OSK 
 — 只会开主线，然后选择第一个宝物。刷新次数为 0 且没找到赌木，会 ZS 重开 ；
 找到赌木会 暂停游戏 ，如果设置了通知程序，会触发程序发送游戏暂停消息。
 `n邪修秘境 
 新 · 独立模式 
 — 打开后 其他所有功能无效 ，仅针对boss 进行自动化。
 ⚙️ 通关后，点击BOSS挑战，选好BOSS，然后启动脚本就可以不用管了。 
 `n⚡ 自动功能`n自动秘境 
 常规 
 — 开启后游戏结束会自动进入秘境，直到秘境失败。
 ⚠️ 秘境成功可能会导致不退出（作者正在解决）。 
 `n自动 F4 
 5-5 触发 
 — 开启后，过完主线 5-5 会自动清理怪物并关闭主线，避免卡关。
 一局游戏只会触发一次 ，不会重复执行。 
 `n自动清理 
 背包整理 
 — 连续指定游戏次数后，触发自动分解装备、传家宝、合成宝石。
 ⚠️ 请提前在程序中设置好 清理品质 和 锁 ，防止误清重要装备！程序不会修改规则。 
 `n奥数增伤 
 新增 
 — 开启后会优先拿 奥数激光 → 瓦解光线，奥数射线 → 焦点 四张卡。
 `n关闭羁绊 & 升级武器 
 可选 
 — 支持在程序中 单独关闭 羁绊合成和武器升级功能，以适应不同打法需求。
 `n自动声望 
 新 
 — 开启后游戏会自动去打声望。如果检测到可获得声望为 0，则按照常规运行。
 赌木模式不会触发 自动声望和清理背包。 
 `n🔧 参数设置`n龙珠数量 
 宝物配置 
 — 买了宝物的大佬设置为 6 ，没买的就是 7 。
 `n等待时长 
 容错 
 — 开始游戏到关卡页面、开始游戏到主线页面的等待时长，请根据自己的网络/硬件估算。
 ⏱️ 长了没影响，短了会导致异常。 
 `n单局时长 
 配合通知 
 — 配合通知程序使用，超过这个预估时间，会发送 异常超时消息 给程序。
 📨 如果不使用通知程序，可以不设置此项。 
 `n⌨️ 快捷键`nShift + F12 
 紧急停止 
 — 一键关闭程序（紧急停止所有操作）。
 `n💡 提示： 程序通知功能已在“赌木模式”和“单局时长”中集成说明。如不使用通知程序，相关设置可忽略。
