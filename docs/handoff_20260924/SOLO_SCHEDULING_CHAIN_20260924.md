# 单人调度链路（2026-09-24，上线版）

给本地实测和后续 agent 用：一局单人从进房到下一局，每一步谁先谁后、看什么信号、trace 里会打出什么字。
全部是**模板匹配 + 简单阈值**，阈值都是 Owner 给的初值，实测后再调。代码以
`src/shuabao/mediator.py` 的 `_tick_main_line` 为准；本文和代码冲突时以代码为准，并回写本文。

核心原则：
- **每个 tick 最多做一件事**：从上往下找到第一件该做的事，做完就返回，下一帧重新从头判断。
- **看不清就零输入**：锚点、卡名、木材读不出时不猜、不盲点（AGENTS.md §5）。
- **事务独占**：点了一下要等回执的事（选卡、进化、黑商购买、用道具），回执确认或超时前不开新事。

## 一、跨局主链

```
L0 大厅 ─ 每局新建房 → 房间开始 → 选关（按看板配置；连续失败自动降一级）→ 开始
   │
L1 局内 ─ 每 tick 按第二节的梯子做一件事；硬超时 3600s（round_timeout_s）到了就记 TIMEOUT 退出
   │
战后 ─ 继续游戏 → 存档面板 → NPC 广场 →（按配置）传家宝 / Boss / 大秘境 → 退出 → 回 L0
```

| 环节 | 信号 | trace 关键字 |
|---|---|---|
| 连败降级 | 连续失败 `downgrade_after_failures` 局 | `[med] 降级 X→Y（连续失败 N 局）` |
| 硬超时 | 进局满 3600s | `round hard deadline 到期` |
| 局内不健康帧 | 截图/窗口持续异常 60s | `局内阶段不健康帧持续超过 60s，停止运行` |

## 二、局内每 tick 的优先级梯子（单人）

从上到下，命中即做、做完返回。

### P0 局面归属（零输入或退出）
1. 战后结果页（胜利/存档/NPC 广场/暂停）先于一切局内动作，走战后链。
2. 硬超时到期 → TIMEOUT 退出。
3. 失败恢复（强失败锚点门控）。
4. 有待确认的动作（PendingAction）→ 等回执，不做新动作。

### P1 画面与焦点
5. 看板丢失（看不到羁绊/技能/宝物栏）两帧确认 → **F1**（规则 3）。
6. 战斗主画面飞走（小地图白框偏离阵地 >0.12，间隔 ≥2s 两帧确认）→ **F2**，每 8s 最多一次（规则 4）。trace：`战斗主画面阵地已学习`、`按 F2 返回阵地`。
7. KK 平台/活动弹窗 → 先 Esc，关不掉再点叉（规则 19）。

### P2 进行中的界面（独占）
8. 中央选卡面板（F/G/V 已打开）→ 走选卡策略（第三节）。
9. 英雄三选一、装备词条、黑商 5 槽 FSM、进化反馈等待、道具使用后的 settle 窗 → 只处理这件事。
10. 界面冲突或未知 → 零输入。

### P3 局内开关（低频）
11. 自动任务勾选、四个挑战开关、提前挑战 Boss、5-5 后关主线挑战、F4 清压力；开局禁卡选择期不主动开面板。

### P4 紧急资源（Owner 2026-09-24）
12. **神器 CD 到了就放；进化金条亮着就点进化**（进化没用完前物品栏一格都不点，规则 1）。
13. **吃吞噬丹**：羁绊栏 ≥6/10 且物品栏有丹 → 点丹，回执是羁绊格数变少（规则 24）。
    **亡灵例外**：手里有亡灵卡、羁绊栏还没出现兵主 EX 时整段不吃，也不为买丹去黑商（规则 27）。
14. **插队去黑商**（规则 25，冷却 45s，绕一趟后回到被打断的那一步）：
    - 羁绊栏 ≥6/10 且物品栏没丹 → trace `羁绊栏已占 N/10 格且物品栏没有吞噬丹，插队去黑商`；
    - 木材 < 500 → trace `木材 N < 500，插队去黑商`。
    黑商不在场时按 **H** 开店（规则 26）：`按 [H] 打开黑商寻找吞噬丹` / `按 [H] 打开黑商买木材`。
    店里按 吞噬丹 → 木材礼包 → 已识别的 2/5 折 的顺序买，买丹时预留杀敌数。
15. 物品栏 2–6 满（≥4 格占用）→ 逐格左键试用（规则 16）；溢出且背包有空 → **Z** 拾取。

### P5 主战力：开哪个面板（`_solo_plan_panel`）
16. 木材 < 500 且技能积压 ≥4 → 先开 **G**（规则 5）。
17. 木材 ≥ 1000 → 开 **F**（规则 7）；木材 ≥ 500 且基础羁绊未成型 → 开 **F**（规则 6）。
18. 技能积压 → **G**。
19. 否则按轮换步：该 F 就 F，该 G 就 G；宝物角标 >0 → **V**（规则 9）。角标为 0 的步直接跳过。

### P6 支线轮换
20. 顺序：`羁绊 → 技能 → 羁绊 → 技能 → 宝物 → 进化 → 装备 → 拾取 → 黑商 → 神器`，循环。
21. 15s 没有任何动作 → 活性看门狗推进到下一步；主线关卡 90s 没推进（或挑战失败）→ 停滞模式：技能积压 1 点就先点 G，F 只拿有直接战斗效果的卡。

## 三、F 面板里拿哪张（`choose_action`）

一页里按下面顺序找第一张可拿的：

1. 必拿（祝福）；
2. 差一张就能合成的卡；
3. **还没拿到的勾选基础羁绊**，顺序 祝福 → 成长 → 经济 → 挑战 → 力量线 → 智力线 → 敏捷线 → 其他基础卡（贪婪在最前）（规则 8、20）；
4. 已持有、还能合成升级的卡；
5. **当前高级卡组**的卡（同一时刻只推进一组）；
6. 白名单里的其它卡（按上面的顺序）；
7. 都没有 → 刷新，最多 3 次 → 关面板。

高级卡组：
- 不设硬门槛（不等基础 80%、不等 480s），单独出现就拿（规则 15）。
- 看板勾了多组时按勾选顺序一组一组来；羁绊栏认出该组的蓝色 EX（海盗为红框 UR）才解锁下一组（规则 21）。trace：`羁绊栏出现第 N 张 EX，解锁下一组高级卡组`。
- EX 靠合成得到，不从面板拿（规则 22）。

## 四、木材三档（一个数 500，一个数 1000）

| 木材 | F 每次最多 | 优先 | 支线 |
|---|---|---|---|
| < 500 | 1 张 | 技能积压先点 G | 插队黑商买木材 |
| 500–1000 | 2 张 | 基础羁绊未成型先点 F | 正常轮换 |
| ≥ 1000 | 15 张 | F 压过技能积压 | 正常轮换 |

读不出木材时不按木材做任何决定（不阻挡基础羁绊，也不插队黑商）。

## 五、长线兜底（现状）

已有：单局 3600s 硬超时、活性看门狗 15s、主线停滞 90s、不健康帧 60s 停止、每局新建房、连败降级、失败取证包。
还缺（上线主线第三块）：业务进度看门狗（比如 10 分钟羁绊/技能/关卡都没进展）、跨局健康统计、异常通知。
