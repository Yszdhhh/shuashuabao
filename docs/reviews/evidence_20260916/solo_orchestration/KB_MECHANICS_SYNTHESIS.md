### 2.1 卡面结构（实测 G1:f0258、G3:f0042/f0067/f0218/f0273/f0109）

从上到下依次是：
1. **稀有度字母徽标**（N 绿 / R 蓝 / SR 紫 / SSR 橙，另有 UR / EX）
2. “荐”角标（几乎每张都有，含义未知）
3. **标题 = 套装/家族名，可合成的套装后跟 (x/y)**，例如 `祝福(0/3)`；高级卡组的开组卡和成员只写组名，不带进度，例如 `封神`、`三国`、`异火`、`亡灵`
4. 图标
5. **散件名**（智力祝福、贪欲金币、雷震子……）
6. 属性行、[效果n]
7. “激活[X]套装效果: …”

- **need 属于套装（标题），不属于散件。** 同一套装同屏会给不同散件，例如 `祝福(0/3)` ×3 分别是敏捷祝福、智力祝福、力量祝福。进度随拿卡递增（G3 trace：祝福 0/3→1/3→2/3）。

### 3.4 哪些家族“按标题认出就能直接拿”（建议，推断）

**局内禁用卡组（新发现，KB 空白）**：开局有“选择当局禁用卡组”弹窗（G3:f0042：刀刀/龙族/修仙/封神/大圣/海盗/三国/异火/亡灵/军团/神兽，“剩余禁用次数: 0”）和“禁用技能”。三局都禁了**大圣再临、神兽、龙族、军团**和**普攻、飓风、火球**。

## 7. 对编排的启示（重点）

### 7.1 一局的预算（推断，基于 §1 实测速率）

| 预算 | 5-5 / 提前挑战窗口（约 10–16 分钟） | 推导 |
|---|---|---|
| 木材 | 约 900 + 4.5–5.5/s × 600–960s ≈ **3.6k–6.2k** | §1.1 |
| F 抽数 | 前 5 抽合计约 300 木，之后 100/抽 → **约 35–55 抽** | G1/G2/G3 实拿 34/43/39 抽，与此吻合 |
| Owner 勾选的羁绊总张数 | 基础 5 组 16 张 + 法术/急速/魔能/暴击/魔术 12 张 + 3 门卡 12 张 + 3 线后三环 30 张 + 封神、海盗 → **≥70 张，约 7000+ 木** | 张数来自 bond_stack_catalog |
| 技能点 | Lv≈18–20 → 约 20–24 点 | §1.2 |

结论：**木材只够配置的一半左右，而技能点是白给的**，不花就直接浪费。所以编排本质上是“在 35–55 抽里排优先级 + 技能点尽快清零”，不是“羁绊做完再点技能”。

### 7.2 现行“基础卡 80% 锁 F”的问题

1. **口径**：`_bond_base_progress_pending`（`WT\src\shuabao\mediator.py` L3274-3285）和 `_bond_base_ready`（`WT\src\shuabao\choice_policy.py` L1376）统计的是“**每个基础家族至少拥有 1 张卡**”的家族数，不是“套装完成”的家族数。基础家族 = bonds 5 个 + 属性门卡 3 个 + 非高级 cards 5 个 = **13 个**，80% 需要 11 个。
2. **G3 实况**（推断，由 trace 和代码得出）：
   - 碰到的基础家族是 10/13（祝福、成长、法术、急速、魔能、魔术、敏捷、经济、暴击、挑战）。
   - 智力、力量（conf 0.9，面板出现 ≥6 次）和贪婪（模板 0.945，出现 3 次）都**出现过但一直没选**，因为“已持有合成优先”（`choice_policy.py` L1326）和属性链后续环排在它们前面。
   - 5:21 木材见底（143），锁一直没解开，封神/海盗一张没拿。
3. **80% 这个阈值和预算脱节**：它没有考虑木材、技能积压和主线进度。
